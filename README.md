# Agentes de Orientação de Carreira em Tecnologia com Microsoft Copilot

## 💻 Sobre o Projeto

Este projeto desenvolve prompts para dois agentes de IA no Microsoft Copilot especializados em orientação de carreira na área de tecnologia. Os agentes trabalham em conjunto para fornecer uma experiência completa de aconselhamento profissional, desde a identificação de interesses até a criação de planos personalizados.

## 🤖 Agente 1: Entrevistador de Carreira em Tecnologia

### Função Principal
- Realizar uma entrevista de 7 perguntas para entender interesses, experiência, disponibilidade e objetivos.
- Sugerir 3 carreiras ranqueadas com base nas respostas.
- Transferir os dados coletados para o Agente 2.

### Estrutura da Entrevista
1. O que mais atrai em tecnologia (resolver problemas, criar produtos ou entender sistemas)?
2. Já tem experiência na área ou está começando?
3. Quantas horas por semana consegue dedicar aos estudos?
4. Prefere lidar mais com pessoas, dados ou código?
5. Objetivo principal (primeiro emprego, transição ou crescimento)?
6. Quais assuntos/tecnologias despertam interesse?
7. Experiência prévia a aproveitar?

### Saída
Após as respostas, o agente analisa e sugere carreiras adequadas, passando as informações para o próximo agente.

## 🤖 Agente 2: Planejador de Carreiras

### Função Principal
- Criar visão do dia a dia da carreira escolhida.
- Desenvolver mapa de habilidades necessárias.
- Elaborar roadmap de 90 dias.
- Sugerir projetos de portfólio.
- Fornecer roteiro de entrevistas.
- Indicar trilha de estudos na DIO.

### Dados Recebidos
- Carreira escolhida
- Horas semanais disponíveis
- Nível de experiência
- Objetivo profissional
- Preferência (pessoas/dados/código)
- Interesses específicos

## 🎯 Objetivos

Após concluir este projeto, você estará apto a:
- Desenvolver planos de desenvolvimento profissional personalizados
- Utilizar prompts eficazes em ferramentas como Microsoft Copilot, Gemini, entre outros

## 🚀 Como replicar

- Copie o prompt do Agente 1 no Microsoft Copilot ou em outra IA de sua preferência.
- Responda às perguntas.
- Copie a saída e cole para o Agente 2 para gerar seu plano.

🧩 VISÃO DO DIA A DIA

Como é o trabalho de um(a) Analista de BI:

- Extração e Limpeza: Conectar-se a diferentes fontes de dados (SQL, APIs, Planilhas) e garantir que a informação esteja correta.

- Modelagem de Dados: Criar relacionamentos entre tabelas para que os cálculos funcionem de forma eficiente.

- Criação de Dashboards: Desenvolver visualizações que respondam a perguntas de negócio de forma clara.

- Análise de Tendências: Identificar padrões nos dados que ajudem os gestores a tomar decisões.

- Reunião com Stakeholders: Entender quais problemas os líderes precisam resolver para traduzi-los em indicadores (KPIs).

🚀 PROJETO DE PORTFÓLIO

PROJETO: Dashboard de Performance de Vendas e Previsão de Churn (IA Light)

O QUE FAZER:
Criar uma solução de BI ponta a ponta usando uma base de dados pública (como Olist ou Kaggle). Você deve realizar o ETL no SQL, criar o modelo no Power BI e adicionar uma camada de análise preditiva simples usando Python ou as funções nativas de IA do Power BI.

ENTREGÁVEIS:

- Script SQL de limpeza de dados.

- Dashboard interativo com pelo menos 3 visões (Executiva, Operacional e Tendências).

- Documentação no LinkedIn explicando o problema de negócio que você resolveu.

CRITÉRIOS DE ACEITAÇÃO:

- O modelo de dados deve estar em Star Schema.

- Não deve haver cálculos complexos "dentro" dos visuais (usar medidas DAX).

- O dashboard deve ser legível em menos de 10 segundos.

DICA: Use sua experiência prévia em Java ou PHP para automatizar algum processo de coleta de dados; isso mostrará sua versatilidade técnica.

💬 ROTEIRO DE ENTREVISTAS

PERGUNTA 1: Como você lida com dados inconsistentes ou faltando na fonte?
COMO RESPONDER: Explique seu processo de limpeza no ETL (Power Query ou SQL), mencionando que primeiro identifica o impacto no negócio e depois decide se deve imputar valores, remover linhas ou reportar o erro à origem.

PERGUNTA 2: Qual a diferença entre uma medida e uma coluna calculada no Power BI?
COMO RESPONDER: "Colunas calculadas ocupam memória e são calculadas no carregamento. Medidas são calculadas em tempo de execução com base no contexto de filtro, sendo mais eficientes para performance."

PERGUNTA 3: Como você explicaria um gráfico complexo para um diretor que não é técnico?
COMO RESPONDER: Use a técnica do Storytelling. Foque no "O que esse dado está nos dizendo para fazer amanhã" em vez de explicar o eixo X ou Y.

PERGUNTA 4: Já trabalhou com grandes volumes de dados? Como garantir a performance?
COMO RESPONDER: Fale sobre reduzir o número de colunas importadas, usar tipos de dados corretos e realizar o máximo de transformações possíveis na fonte (Query Folding).

PERGUNTA 5: Por que você está migrando da área acadêmica/autônoma para o mercado corporativo agora?
COMO RESPONDER: Destaque que os 2 anos de projetos te deram a base técnica necessária e que agora você busca aplicar essa capacidade analítica para gerar impacto financeiro e escala em problemas reais de mercado.
